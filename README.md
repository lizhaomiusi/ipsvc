# ipsvc 直播源

天空电视用的直播源备份，国内通过 ghfast.top / gh-proxy.com / jsdelivr 等镜像访问。整理日期：2026-11-01。

- `sources.txt`：源列表，每行“名称,地址”，可以直接粘进天空电视手机遥控页面的“源列表”
- `*.m3u`：各个源的频道列表

单个源地址形如：`https://raw.githubusercontent.com/lizhaomiusi/ipsvc/main/guovin.m3u`
